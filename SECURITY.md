# Security

Please do not report a vulnerability through a public issue. Use GitHub's
private security advisory flow for this repository.

Never include API keys, credentials, private files, customer data, benchmark
answers, private receipts, or non-public research content in an issue or pull
request.

This repository contains no CASP private runtime and does not accept customer
data. Any future public client will undergo a separate security review before it
is added here or released elsewhere.
